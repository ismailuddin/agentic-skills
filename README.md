# Agent skills

> This repo holds various useful skills for agentic software
> development.

## 🚀 Usage

The skills in this repo are written on the format defined by the Vercel Labs
[Skills](https://github.com/vercel-labs/skills) package.

1. Install all the skills by running `npx skills add https://github.com/ismailuddin/agentic-skills`

To install just a specific skill, run `npx skills add https://github.com/ismailuddin/agentic-skills --skill migrate-to-uv`.
